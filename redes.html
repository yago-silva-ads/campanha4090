🤖 Responder como Luciano via API

A API do Meta permite responder comentarios automaticamente como a Pagina Lucianodaluz.

Como funciona:

1. O n8n recebe o comentario via webhook
2. A IA gera uma resposta no tom do Luciano
3. O n8n posta via POST /{comment-id}/replies
4. O comentario aparece como resposta da Pagina

⚠️ Importante: Para Instagram, a API so funciona em comentarios de posts da propria conta. Respostas em posts de terceiros devem ser manuais.

O workflow "Resposta Segura" ja esta ativo no n8n Cloud com intervalo de 3h.
